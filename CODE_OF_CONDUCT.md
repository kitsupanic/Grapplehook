# Code of conduct

Grapplehook follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). It applies to issues, pull requests, discussions and anywhere else you represent the project.

## Reporting

If someone breaks it, contact the maintainer, [kitsupanic](https://github.com/kitsupanic), through the contact details on their GitHub profile. Reports are kept private. You can also use GitHub's **Report content** option on any comment.

The maintainer may remove comments, close threads, or block anyone who breaks this code, following the Covenant's [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
